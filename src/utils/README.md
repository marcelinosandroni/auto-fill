# 🛠️ Utils (Helpers Puros)

Funções utilitárias puras (sem efeitos colaterais).

## Regras
1. **Funções puras** - Mesmo input = mesmo output
2. **Sem dependências externas** - Apenas TypeScript
3. **Bem testadas** - Unit tests obrigatórios

## Exemplos
- `formatDate()` - Formatar datas
- `extractOTP()` - Extrair códigos OTP de texto
- `encrypt()` - Criptografar dados
- `validateEmail()` - Validar emails
